### 1.2 技术栈推荐

考虑到项目特点（学生话剧、预算有限、复古风格、移动端优先），推荐：

**方案 A：纯静态网站（推荐）**
- **技术栈**：HTML5 + CSS3 + JavaScript（原生或轻量框架）
- **构建工具**：Vite（快速、现代化）
- **部署**：GitHub Pages / Vercel / Netlify（免费）
- **优势**：零成本、加载快、维护简单、适合二维码扫描场景

**方案 B：轻量动态网站**
- **技术栈**：Vue 3 / React + Vite
- **CMS**：Decap CMS（原 Netlify CMS）或 Strapi
- **部署**：Vercel / Netlify
- **优势**：内容管理方便，适合后续频繁更新

**方案 C：静态站点生成器**
- **技术栈**：Hexo / Hugo / Astro
- **部署**：GitHub Pages
- **优势**：Markdown 写作、自动生成页面、性能好

fetch('/data/characters.json')
  .then(res => res.json())

## 五、部署方案对比

| 平台 | 费用 | 优势 | 劣势 | 推荐度 |
|------|------|------|------|--------|
| **GitHub Pages** | 免费 | 稳定、与 Git 集成好 | 国内访问慢、不支持后端 | ⭐⭐⭐ |
| **Vercel** | 免费 | 速度快、自动 HTTPS、全球 CDN | 需要科学上网管理后台 | ⭐⭐⭐⭐⭐ |
| **Netlify** | 免费 | 功能丰富、表单处理 | 国内访问一般 | ⭐⭐⭐⭐ |
| **阿里云 OSS** | 按量付费 | 国内访问快、稳定 | 需要备案、有成本 | ⭐⭐⭐⭐ |
| **腾讯云 COS** | 按量付费 | 国内访问快、微信生态 | 需要备案、有成本 | ⭐⭐⭐⭐ |

**推荐方案**：Vercel（免费、快速、简单）
