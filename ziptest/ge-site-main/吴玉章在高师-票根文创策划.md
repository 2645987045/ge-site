# 《吴玉章在高师》票根文创策划方案

## 一、项目概述

| 项目 | 内容 |
|------|------|
| 话剧名称 | 《吴玉章在高师》 |
| 话剧类型 | 学生话剧，严肃庄重正剧风格 |
| 主题内容 | 吴玉章先生生平事迹 |
| 文创品类 | 纪念票根（第一期） |
| 票根定位 | 纪念收藏品，非实际入场券 |

---

## 二、票根设计规格

### 2.1 物理规格

| 参数 | 规格 |
|------|------|
| 尺寸 | 210mm x 70mm（标准演出票根尺寸） |
| 材质 | 牛皮纸（建议 120g-150g） |
| 印刷 | 复古做旧风格，单色或双色印刷（建议深棕/暗红 + 黑色） |
| 工艺 | 哑光覆膜（可选），增加手感与耐久性 |
| 裁切 | 左侧预留虚线撕裂线，模拟真实票根体验 |

### 2.2 视觉风格

- **整体调性**：复古做旧，呼应民国/早期高等教育历史氛围
- **色彩方案**：以牛皮纸原色为底，搭配深棕、暗红、墨黑等沉稳色调
- **字体建议**：标题使用衬线体/书法体（如方正清刻本悦宋），正文使用楷体或仿宋
- **装饰元素**：可做旧边框、印章纹样、老票据底纹、细线分隔等传统票据元素
- **差异化亮点**：票根融合数字互动（二维码），实现"复古外壳 + 现代内核"

---

## 三、票根内容规划

### 3.1 正面（主视觉面）

**正面内容清单：**

- 剧名《吴玉章在高师》（突出展示）
- Slogan / 宣传语（后期确定后加入）
- 主视觉图形（Logo、吴玉章先生剪影、或高师建筑元素等）
- 演出信息（时间、地点、场次——即使是纪念品也印上"首演"信息，增强仪式感）
- 二维码（引导语："扫码探索话剧世界"或"扫码进入高师记忆"）

### 3.2 背面（内容面）

**背面内容清单：**

- 收藏编号（如 No.001、No.002，限量编号增加收藏价值）
- 经典台词节选（1-2句，从剧中精选）
- 吴玉章先生名言（1句）
- 剧情梗概或创作背景（2-3行简短文字）
- 制作团队信息（出品方、监制、设计等）

---

## 四、配套网站规划

### 4.1 网站入口

- 票根正面二维码为唯一入口
- 建议网站域名简洁易记

### 4.2 首期内容模块

| 模块 | 内容说明 |
|------|---------|
| 介绍视频 | 话剧宣传片/预告片，建议 2-5 分钟 |
| 角色档案 | 剧中主要角色的介绍、饰演者信息、角色历史原型 |
| 幕后花絮 | 排练照片、幕后故事、主创访谈 |

### 4.3 后续可扩展模块

- 吴玉章先生生平史料专区
- 观众留言墙 / 互动区
- 隐藏彩蛋（如未公开剧照、导演手记等）
- 其他文创产品展示与购买入口

### 4.4 网站风格建议

- 与票根的复古做旧风格保持统一
- 配色以暖色调为主，搭配历史感纹理背景
- 响应式设计，适配手机扫码后浏览

---

## 五、执行排期（建议）

| 阶段 | 任务 | 建议周期 |
|------|------|---------|
| **第一阶段：内容准备** | 确定 slogan、精选台词/名言、撰写梗概 | 1 周 |
| **第二阶段：视觉设计** | 票根正反面设计稿（含 2-3 版方案对比） | 1-2 周 |
| **第三阶段：网站搭建** | 网站基础框架搭建 + 首期内容上线 | 2-3 周 |
| **第四阶段：打样确认** | 票根印刷打样、色彩校对、材质确认 | 1 周 |
| **第五阶段：批量印刷** | 确认终稿后批量印刷 | 1-2 周 |
| **第六阶段：发放使用** | 演出现场发放 / 搭配其他文创组合发放 | 演出日 |

## 七、AI 辅助执行清单

以下是可以用 AI 辅助完成的具体任务：

- [ ] **Slogan 创作**：根据话剧主题生成多组宣传语供选择
- [ ] **台词精选**：从剧本中提取最具代表性的台词
- [ ] **名言整理**：整理吴玉章先生的经典语录
- [ ] **剧情梗概撰写**：撰写 2-3 行的票根背面简介
- [ ] **票根设计稿**：生成复古做旧风格的票根视觉设计
- [ ] **网站页面设计**：设计与票根风格统一的网站 UI
- [ ] **二维码生成**：生成指向网站的二维码
- [ ] **收藏编号系统**：设计编号规则（如按场次、按日期等）

## 八、后续文创扩展方向（第二期）

在票根文创成熟后，可逐步扩展至：

- 主题笔记本 / 手账本（封面印剧目海报，内页印台词节选）
- 场刊 / 演出手册（完整剧情介绍 + 主创团队 + 幕后故事）
- 明信片套装（剧照 / 插画 / 名言）
- 金属书签（吴玉章先生剪影 / 高师建筑轮廓）
- 徽章 / 胸针（剧目 Logo / 经典元素）
- 帆布袋（slogan + 主视觉）
