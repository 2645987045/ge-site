## 一、录制准备（5 分钟）

1. 浏览器打开 `#cinema` 链接，按 `F11` 全屏。
2. 影院模式会自动开始一次"点火演示"并无限循环，一轮约 **13 秒**，不用手动操作。
3. 录屏二选一：
   - Windows 自带：`Win + G` 打开 Xbox Game Bar → 点录制（或 `Win + Alt + R` 直接开始）。
   - OBS：新建"显示器采集"，画布 1920×1080，帧率 60，码率 ≥ 12000 Kbps。
4. 把鼠标移到屏幕外 / 开启"隐藏指针"，避免画面里有光标。
5. 连续录 **2–3 轮循环**（约 40 秒素材），后期挑最干净的一轮用。
6. 想要"自己调旋钮"的镜头：退出影院模式（右上角 ✕），在普通界面拖滑块 + 点"发射"，单独录一段。

## 三、口播稿（约 85 秒，剪映"文本朗读"或自录）

如果我想在地球上点一颗星，需要什么？
答案可能出乎意料：一颗比胡椒粒还小的燃料丸，和一瞬间顶得上千场雷暴的激光。
这就是惯性约束聚变。
看，数十道激光在同一瞬间聚焦到靶丸表面，把它的外层烧成等离子体向外喷走。
喷走的物质像火箭尾气，反作用力把剩下的壳狠狠往里推——上千亿个大气压。
壳向内飞奔、急刹车，动能全部变成热：体积缩到千分之一，温度飙到上千万度。
够热、够密，α 粒子自己加热自己，火就点着了。
2022 年，美国 NIF 第一次做到：输入 2.05 兆焦，输出 3.15 兆焦，人类第一次在实验室拿到聚变净能量增益。
在中国，神光系列装置已经走了四十多年，下一代点火装置正在路上。
现在，旋钮给你。调能量、调脉冲、调靶丸大小，看你能不能点着这一颗星。
我是嗝，一个痛苦学物理的本科生。这是我的栏目《可玩物理》，第一期，完。
